# 🛒 বাজার দর | BazarDor

### Your Daily Market Price Companion 🇧🇩

**বাজার দর (BazarDor)** is a modern, responsive web application designed to help users explore everyday product prices in Bangladesh. It provides an easy way to browse products, compare prices, and stay informed about market rates through a clean and user-friendly interface.

## ✨ Key Features

- **🛍️ Product Listings** — Browse everyday products with their names, images, units, and prices.
- **💰 Price Comparison** — Compare product prices to make smarter shopping decisions.
- **🇧🇩 Bangla Language Support** — View product information and prices in Bangla for a localized experience.
- **📱 Fully Responsive Design** — Enjoy a seamless experience across mobile, tablet, and desktop devices.
- **🔐 Authentication** — Secure user authentication with Better Auth for supported account features.

## 🛠️ Technologies Used

| Technology | Purpose |
| --- | --- |
| Next.js | Build the user interface and web application |
| Next.js App Router | Manage routing, layouts, and navigation |
| TypeScript / JavaScript | Develop application logic and functionality |
| Tailwind CSS | Create responsive and modern designs |
| DaisyUI / Hero UI | Build reusable UI components |
| Better Auth | Handle user authentication |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/MrArg3/Bazar-Dor
```

### 2. Navigate to the Project Directory

```bash
cd YOUR_REPOSITORY
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the root directory and add the environment variables required by your application.

```env
# Add your required environment variables here
```

**Note:** Configure the appropriate Better Auth secret, base URL, and database settings if your project requires them. Never commit real secrets or credentials to GitHub.

### 5. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
